Access commands

telnet, shell, persist and download — obtaining and keeping a root shell, and moving files.

telnet

mutating

Tries the known telnet/ADB payloads in order and verifies port 23. The working method is a command injection in the ids field of the REMOVE_WHITE_SITE goform, which runs /bin/busybox telnetd -l /bin/sh on the router. TZ_CMD_SECURE_LOGIN is kept as a fallback. The firmware's sha256() returns a hex string that is then Base64-encoded, and every command needs isTest=false. Both are handled automatically.

./zlt_xloader --dry-run=false telnet
Runtime only

The telnetd started by this command does not survive a reboot. Use persist or rerun the command after restarting the router.

shell

interactive

Interactive root shell over telnet or SSH. Telnet is enabled automatically if the port is closed. The client handles Telnet IAC negotiation.

./zlt_xloader shell
--sshUse SSH instead of telnet (credentials from the active profile).
--user / --passwordOverride SSH credentials.
--commandRun one command instead of opening a session.
--atSend the command as a raw AT command via /bin/at_cmd.
./zlt_xloader shell --command "nv get sim_plmn"
./zlt_xloader shell --at --command "AT+CSQ"
./zlt_xloader --target 192.168.1.1 shell --ssh

persist

mutating

Appends a small block to /etc/rc so BusyBox telnetd (23) and dropbear (22) start at every boot, and sets the firmware's telnetd_enable, adbd_enable and dropbear_enable NVRAM flags. The original boot script is backed up to /etc/rc.zlt-backup. The command is idempotent. On this firmware, ADB binds only 127.0.0.1:5037 (host mode) and needs USB; network ADB on 5555 is not available without additional firmware support.

./zlt_xloader --dry-run=false --yes persist --reboot
--rebootReboot the router after applying the change.

download

mutating

Exports a file from the router through a local HTTP endpoint: the tool starts a local server and runs curl -T from the router shell. The same approach is used by the reference project.

./zlt_xloader --dry-run=false --yes download --remote /etc_ro/default/default_parameter_sys --local ./config.txt
--remotePath of the file on the router.
--localDestination path on this machine.
Windows / Git Bash

MSYS converts Unix-style arguments such as /etc_ro/... into Windows paths. Prefix the command with MSYS_NO_PATHCONV=1 when using --remote.
