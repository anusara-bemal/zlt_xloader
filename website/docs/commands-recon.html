Recon commands

scan, status and version — read-only inspection of the device and the binary.

Every command accepts the same global flags:

FlagPurpose
--targetRouter address, for example 192.168.1.1.
--timeoutPer-request timeout.
--profilePath to an alternate JSON device profile.
--dry-runtrue by default; set to false to allow writes.
--verboseDetailed request and response logging.
--jsonMachine-readable output.
--yesSkip interactive confirmation prompts.

scan

read-only

Reachability check, TCP port scan and firmware/model fingerprinting. Reports the active profile, firmware string, model and ACS URL. Nothing is written to the device.

./zlt_xloader --target 192.168.1.1 scan
--portsComma-separated port list (default 23,80,8080,7547).

status

read-only

Device, SIM, lock, signal and NVRAM status. Values are read through a shell, so the reported lock state is the real NVRAM state even when the web API returns empty values.

./zlt_xloader status

version

local

Prints the version, commit and build date injected at build time. Useful when checking whether a firmware fix is present in the binary you downloaded.

./zlt_xloader version
